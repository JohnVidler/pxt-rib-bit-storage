## Enum `R1Response`

R1 status bits from SD command responses.

- `IDLE_STATE = 0x01`
- `ERASE_RESET = 0x02`
- `ILLEGAL_COMMAND = 0x04`
- `CRC_ERROR = 0x08`
- `ERASE_SEQ_ERROR = 0x10`
- `ADDRESS_ERROR = 0x20`
- `PARAMETER_ERROR = 0x40`
- `VALID_RESPONSE = 0x00`
